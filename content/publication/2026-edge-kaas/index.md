## Overview

**KaaS-Edge** introduces a resource-aware **Knowledge-as-a-Service (KaaS)** framework for collaborative edge intelligence via **Knowledge Distillation (KD)** in heterogeneous wireless edge networks, presented at **IEEE EDGE 2026** in Sydney, Australia.

## Key Contributions

- **Heterogeneity-Aware Service Provisioning**: Accounts for diverse local computation capacities, memory limits, and wireless channel states across edge nodes.
- **Lightweight Knowledge Exchange**: Replaces heavy parameter synchronization with soft-output knowledge distillation to overcome wireless communication bottlenecks.
- **Resource Optimization**: Jointly optimizes edge node selection and communication-computation resource allocation.
